## What Are AI Skills?

AI skills are structured reference files that teach AI coding tools about a specific library. They follow the [Agent Skills](https://agentskills.io) open standard. When a skill is installed, your AI tool loads these files as context so it can reference the library's actual API and conventions instead of guessing.

React Magma's skill covers imports, TypeScript enums, compound component patterns, theming, and accessibility requirements. It works with any tool that supports the Agent Skills spec.

## Supported Tools

The React Magma skill works with any AI coding tool that supports the Agent Skills spec:

- **OpenAI Codex** (CLI, App, and Web)
- **Claude Code**
- **Cursor**
- **GitHub Copilot**
- **Windsurf**
- **Cline**
- And 40+ other tools

## Installation

If you are contributing to the React Magma repo using Codex, the skill is already configured via `.agents/skills/`. For other tools, run `npx skills add .` from the repo root.

For consumer projects, follow the instructions for your tool below.

### Codex (CLI, App, Web)

Install via the Codex app:

```sh-title-noRender-noCodeSandbox
$skill-installer cengage/react-magma
```

### Claude Code, Cursor, Copilot, and Others

Run this once in your project directory:

```sh-title-noRender-noCodeSandbox
npx skills add cengage/react-magma
```

This auto-detects which AI tools are installed and writes configuration to the correct location for each. To install to all supported tools at once, add the `--all` flag:

```sh-title-noRender-noCodeSandbox
npx skills add cengage/react-magma --all
```

## Verifying the Installation

After installing, test with a prompt like:

> "Build a form with a name input, select dropdown, and submit button using React Magma"

The output should look something like this:

```jsx-noRender-startExpanded
import React from 'react';
import {
  Input,
  Select,
  Button,
  ButtonColor,
  ButtonType,
  GlobalStyles,
  ThemeContext,
  magma,
} from 'react-magma-dom';

export function ExampleForm() {
  return (
    <ThemeContext.Provider value={magma}>
      <GlobalStyles />
      <Input labelText="Name" />
      <Select labelText="Category" items={[{ label: 'Option A', value: 'a' }, { label: 'Option B', value: 'b' }]} />
      <Button color={ButtonColor.primary} type={ButtonType.submit}>
        Submit
      </Button>
    </ThemeContext.Provider>
  );
}
```

If the output uses string literals like `color="primary"`, imports from internal paths, or omits `labelText`, the skill may not be installed correctly.
